# 浏览器扩展上架指南（Edge 加载项 + Chrome 应用商店）

扩展包用 `python scripts/pack_extension.py` 生成，在 `dist/store/`：

| 商店 | 上传这个文件 | 说明 |
|---|---|---|
| Edge 加载项 | `panda-extension-edge-<版本>.zip` | 完整功能 |
| Chrome 应用商店 | `panda-extension-chrome-<版本>.zip` | 屏蔽了 YouTube（商店规定不允许下载 YouTube 视频） |

截图和图标在 `store/screenshots/`。

## 一、Edge 加载项（免费）

1. 打开 <https://partner.microsoft.com/dashboard/microsoftedge/> ，用微软账号登录，注册开发者（个人，免费）。
2. 点「创建新扩展」，上传 `panda-extension-edge-<版本>.zip`。
3. 「可用性」：公开；市场：全部。
4. 「属性」：类别选 **效率（Productivity）**；隐私政策网址填上面表格里的网址；网站填 GitHub 仓库地址。
5. 「商店一览」：语言加 **中文（简体）**，按下面"商店文字"填；上传 `store/screenshots/` 里的图。
6. 「测试说明」：填下面的"给审核员的说明"。
7. 提交。一般几个工作日出结果。

## 二、Chrome 应用商店（一次性 5 美元）

1. 打开 <https://chrome.google.com/webstore/devconsole> ，用谷歌账号登录，付 5 美元注册费。
2. 「新建项目」，上传 `panda-extension-chrome-<版本>.zip`。
3. 「商品详情」：按下面"商店文字"填；类别选 **工作流程与规划 / 工具**；语言 **中文（简体）**。
   图标用 `图标-128.png`，截图用两张 1280x800，小宣传图用 `宣传图-440x280.png`。
4. 「隐私权规范」：
   - 单一用途：见下面"单一用途"。
   - 每个权限的理由：见下面"权限说明"，一条一条贴进去。
   - 是否使用远程代码：**否**。
   - 数据使用：勾选"网站内容"和"身份验证信息"两类都**不**收集到服务器（见隐私政策）；
     三个声明（不出售、不用于无关用途、不用于信贷）全部勾上。
   - 隐私政策网址：同上。
5. 「测试说明」：填"给审核员的说明"。
6. 提交。因为用了 `<all_urls>` 和 `cookies` 权限，会走人工深入审核，可能要一到三周。

## 三、上架之后

两个商店各会分配一个新的扩展 ID（32 个小写字母）。把这两个 ID 发给我，我来做：

- 把新 ID 加进程序的 `EXTENSION_IDS`（不然商店版扩展连不上软件）；
- 安装包写注册表登记这两个扩展，装完软件后浏览器会自动提示"发现新扩展，是否启用"，用户点一下就行；
- 软件里的安装向导改成直接打开商店页面。

## 商店文字

**名称**

熊猫下载器

**简短说明**（132 字以内）

把浏览器下载和网页视频交给熊猫下载器：多连接加速、断点续传、音视频自动合并。需要先安装熊猫下载器桌面程序。

**详细说明**

熊猫下载器是一个开源、无广告的 Windows 下载工具。这个扩展把浏览器和它连起来：

● 接管浏览器下载：点下载链接时自动交给熊猫下载器，多连接加速，断线、关机后都能接着下。按住 Alt 点击可以临时用浏览器自己下载。
● 网页视频：鼠标移到视频上会出现「熊猫下载」按钮，点一下就下载；也可以点扩展图标查看本页发现的视频。
● 右键菜单：下载链接、下载这个视频、下载本页所有文件。
● 需要登录才能下载的文件也能下：扩展会把这个下载地址用到的登录状态交给本机的熊猫下载器。

隐私：扩展只和你电脑上的熊猫下载器通信，不连接任何服务器，不收集、不上传任何数据。

使用前请先安装熊猫下载器桌面程序（Windows 10 / 11）：https://github.com/jethrowong666/panda-downloader/releases/latest

不支持有 DRM 版权保护的视频。请只下载你有权下载的内容。

**单一用途**（Chrome 要填）

把浏览器里的下载任务和网页上的视频，交给用户电脑上安装的熊猫下载器来下载。

## 权限说明（Chrome 要逐条填，Edge 的"测试说明"里也可以贴）

| 权限 | 理由 |
|---|---|
| `downloads` | 发现浏览器开始了一个下载时，取消它并把地址交给熊猫下载器；交接失败时让浏览器继续下载。 |
| `downloads.ui` | 下载被熊猫下载器接管后，不再显示浏览器自己的下载栏，避免出现两个下载提示。 |
| `nativeMessaging` | 和用户电脑上安装的熊猫下载器通信（发送下载地址）。这是扩展的核心功能。 |
| `contextMenus` | 在右键菜单里加"用熊猫下载器下载"。 |
| `cookies` | 只读取"正在下载的那个地址和它的来源页面"的 Cookie，交给本机的熊猫下载器，这样需要登录才能下载的文件也能下。不上传到任何服务器。 |
| `storage` | 保存用户在扩展里的开关（是否接管浏览器下载）。 |
| `webRequest` | 只读取响应头（内容类型、大小），用来发现当前页面加载的视频和音频文件。不拦截、不修改任何请求。 |
| `tabs` | 读取当前标签页的网址和标题，用作下载的来源页和默认文件名。 |
| `scripting` | 用户在右键菜单里选"下载本页所有文件"时，在当前页面里收集文件链接。 |
| 主机权限 `<all_urls>` | 用户可能在任何网站上下载文件或视频，扩展需要在所有网站上显示下载按钮、识别下载链接。 |

## 给审核员的说明

This extension is a companion to "Panda Downloader", an open-source (GPL-3.0) desktop download manager for Windows.
It hands browser downloads and page videos to the desktop app through Native Messaging. It does not contact any remote server.

To test:
1. Download and install the desktop app (Windows 10/11): https://github.com/jethrowong666/panda-downloader/releases/latest
2. Start "熊猫下载器" (Panda Downloader) once so it registers the native messaging host.
3. Click the extension icon: it should show "已连接" (connected).
4. Click any file download link (for example a .zip): the download is handed to the desktop app and a confirm window appears.
5. Open a page with an HTML5 video and hover the video: a "熊猫下载" button appears at its top-right corner.

No account is required. Source code: https://github.com/jethrowong666/panda-downloader
